# 每日 AI 新闻助手 PRD

## 目标
面向希望按个人兴趣阅读 AI 新闻的用户，提供订阅设置、每日自动生成、邮件推送与历史查询。本版用于本地评审，支持多个订阅身份，不提供公开注册、密码登录或租户认证。仅绑定本机；身份选择不是安全登录。

## 用户流程
1. 创建昵称、邮箱、话题、关键词、每日推送时间（北京时间，默认 09:00）。
2. 保存订阅，可修改或停用。停用后不再自动创建新任务。
3. 手动生成预览：立即返回任务编号，展示状态与工具事件，默认不发信。
4. 每日到期运行正式任务，生成成功后提交邮件；查看简报和投递状态。
5. 查看按订阅、日期组织的历史；对明确失败的邮件重新提交。

## 内容规则
- 时间窗口为运行开始前 24 小时，最多 5 条，不足不凑数。
- 标题、摘要、相关性说明使用中文；保留真实来源 URL 与来源时间。未知时间单独标注。
- URL 去重由程序执行，事件级合并由模型判断。所有引用须属于本次采集的新闻编号。
- 没有匹配新闻允许空简报；全部来源失败是错误，不能输出“没有新闻”。
- 邮件仅使用订阅保存的收件人，模型无权更改收件地址。

## 页面
订阅编辑区、简报阅读区、历史列表、工具执行记录。所有操作有加载、空态和错误反馈。执行记录只展示外部可观察事件，不展示隐藏推理。

## 定时与状态
服务每分钟检查到期订阅；仅单进程单 worker。每日正式任务由订阅 ID 与北京日期唯一约束去重。启动后补跑当天到期任务，不追补更早日期。关闭程序期间无调度。
运行状态：queued / running / succeeded / failed / interrupted。邮件状态：sending / accepted / failed / uncertain。accepted 仅表示 SMTP 接受，不代表收件箱已送达。

## 范围
Python、FastAPI、SQLite、原生 HTML/CSS/JS、DeepSeek、QQ SMTP。本地运行优先，提供 Docker。排除 Redis、向量库、IMAP、多 Agent、公开站点、复杂管理后台。运行中的订阅与收件人使用任务创建时快照，后续修改对新任务生效。

## 验收
两种偏好可得到不同内容；刷新和重启后数据保留；手动预览不发信；每日任务不重复；真实模型至少一条完整调用轨迹；邮件实际收件与程序提交状态分别记录。具体用例见实施验收清单，实测结果见验证报告。
