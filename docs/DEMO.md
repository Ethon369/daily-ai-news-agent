# 三分钟演示流程

## 演示前
启动服务并检查模型配置。准备一个已停用自动推送的演示身份，防止录屏期间产生额外任务。提前完成一份真实预览以应对网络延迟，但不要把历史结果当成现场生成。邮件未实际验证时直接说明，只展示模拟测试与状态设计。

## 录屏节奏
1. 0:00–0:25 展示订阅：话题、关键词、邮箱、北京时间推送设置，保存并刷新，说明数据已持久化。
2. 0:25–1:15 点击生成预览，观察真实模型响应与不同工具调用，展开一次参数、结果和耗时。模型结束后展示明确的任务状态；超时或失败应如实展示。
3. 1:15–1:55 阅读一至两条新闻，展示相关性说明、真实来源链接、来源时间和证据范围。若正文失败，展示信息有限标注。
4. 1:55–2:20 切换历史与任务记录，说明手动预览不自动发信，每日正式任务通过唯一约束避免重复创建。
5. 2:20–2:45 展示邮件状态或测试结果，区分 accepted 与实际送达。SMTP 未配置时不声称真实投递成功。
6. 2:45–3:00 展示 README 的启动命令、测试命令及开源参考边界。

## 交付前检查
录屏里隐藏凭据和个人邮箱；保持实际鼠标/页面操作，不用拼接结果伪装实时成功。录屏是可选交付物，本文件是流程脚本，不是已经录制的视频。
