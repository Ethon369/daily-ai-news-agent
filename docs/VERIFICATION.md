## 真实模型与新闻

2026-10-18 的命令行验证：
- 常规场景：Hacker News 返回 15 条窗口内材料，Hugging Face 正常空结果；真实模型生成 4 条简报。
- 部分失败场景：人为注入 Hugging Face 故障，Hacker News 返回 13 条材料（有 5 个条目失败），真实模型仍完成 3 条简报。Hugging Face 故障为测试注入，不是自然服务故障。
- 调用与结果保存在本地 `artifacts/live-normal/`、`artifacts/live-partial/`，未加入 Git。

2026-10-19 的网页真实验证：
- 一个请求因模型 API 网络连接失败而失败；错误被保存并在页面展示。之后增加连接错误的一次重试并验证接口恢复。
- “大语言模型、AI Agent；开源、工具调用”：真实模型 3 轮、11 次工具调用，生成 5 条简报，来源与时间来自已采集索引。
- “AI 对就业和招聘的影响；就业、岗位、招聘、劳动力”：真实模型 3 轮、5 次工具调用，返回空简报，并说明本次来源未找到符合偏好的条目。两种偏好没有返回同一份固定结果。
- 真实网页运行编号、时间与状态记录在 `artifacts/ui/live-runs.json`；简报和事件位于本地数据库及 `data/runs/`。

上述首次验证时，Fake-IP 代理环境下任意文章链接被公网地址校验拦截，原文读取未通过。模型依据新闻索引和可用来源文字生成，界面展示证据范围，结果中说明正文不可读。此结果只能证明索引驱动简报链路，不证明全文摘要质量或内容真实性。

2026-10-19 增加经 HTTPS 校验的公共 DNS 查询，针对 Fake-IP 取得真实公网地址后固定连接；保留内网、保留地址、IPv4 映射地址与重定向校验，不再对新闻源保留连接 Fake-IP 的例外。

- 三个此前失败的历史链接实测成功：arXiv 摘要页 4,525 字符，GitHub README 与博客分别提取到 12,000 字符上限。结果位于 `artifacts/article-fetch/`，不代表完整论文或完整网页均被读取。

- 真实模型与事件记录位于独立的 `artifacts/article-fix-agent/`，没有覆盖原验证材料，未发送邮件。
- 网页端重新生成的预览也已通过：5 条新闻均标注读取了原网页片段，工具事件展示成功读取及超过大小限制的明确失败；截图与运行编号位于 `artifacts/ui/article-fix.jpg`、`artifacts/ui/article-fix-run.json`。旧历史简报未重写。
