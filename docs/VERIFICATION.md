## 自动检查

执行命令：`python -m pytest`、`node --check static/app.js`、`python -m compileall -q app scripts`、`python -m pip check`。

最近完整自动测试：92 通过、1 跳过。跳过项是当前 Windows 权限不允许创建真实符号链接的测试；路径越界、命令组合、受限文件写入等测试已通过，不能把这些测试等同于真实符号链接用例通过。Starlette TestClient 与当前 anyio 组合产生一项弃用警告，不影响本次测试结果，未通过屏蔽警告处理。

覆盖订阅与历史持久化、后台任务、预览不发信、正式任务模拟投递、北京时间到期/跨日/去重、并发任务和投递幂等、重启恢复、工具边界、真实 Bash 的启动环境隔离与超时终止、模型结构校验、循环预算与 API 限流/连接重试。邮件夹具验证认证失败、明确拒绝、提交超时不确定状态和 MIME 编码，均不连接真实邮箱。

## 真实模型与新闻

2026-10-18 的命令行验证：
- 常规场景：Hacker News 返回 15 条窗口内材料，Hugging Face 正常空结果；真实模型生成 4 条简报。
- 部分失败场景：人为注入 Hugging Face 故障，Hacker News 返回 13 条材料（有 5 个条目失败），真实模型仍完成 3 条简报。Hugging Face 故障为测试注入，不是自然服务故障。
- 调用与结果保存在本地 `artifacts/live-normal/`、`artifacts/live-partial/`，未加入 Git。

2026-10-19 的网页真实验证：
- 一个请求因模型 API 网络连接失败而失败；错误被保存并在页面展示。之后增加连接错误的一次重试并验证接口恢复。
- “大语言模型、AI Agent；开源、工具调用”：真实模型 3 轮、11 次工具调用，生成 5 条简报，来源与时间来自已采集索引。
- “AI 对就业和招聘的影响；就业、岗位、招聘、劳动力”：真实模型 3 轮、5 次工具调用，返回空简报，并说明本次来源未找到符合偏好的条目。两种偏好没有返回同一份固定结果。
- 真实网页运行编号、时间与状态记录在 `artifacts/ui/live-runs.json`；简报和事件位于本地数据库及 `data/runs/`。

当前 Fake-IP 代理环境下，任意文章链接被公网地址校验拦截，原文读取未通过。模型依据新闻索引和可用来源文字生成，界面展示证据范围，结果中说明正文不可读。此结果只能证明索引驱动简报链路，不证明全文摘要质量或内容真实性。
